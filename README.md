# Lumina

A local-first, privacy-focused application for cognitive wellness, fusing clinical CBT tools with gamified habit tracking in a premium editorial interface.

## Features (v1.0 MVP)

- **🔒 Local-First & Encrypted:** All data (journal, habits, clinical metrics) is stored locally on your device and encrypted using AES-GCM. Complete privacy by design.
- **🧠 3-Level CBT Journal:** A progressive disclosure journal that guides you from basic self-observation to deep cognitive restructuring.
- **⚙️ Local Distortion Engine:** Automatically detects cognitive distortions on-device using clinical pattern matching, without relying on external AI APIs.
- **📈 Clinical Analytics:** Tracks Subjective Units of Distress (SUDS) and calculates the Cognitive Change Index (ICC) over time.
- **🔥 Gamified Habit Tracking:** The "Momentum Store" rewards consistency with a deterministic XP and leveling system.
- **🎧 Premium Sensory Feedback:** Uses the Web Audio API for subtle, crystal-like sounds and elegant confetti animations.
- **🌙 Night Ritual & Sleep CBT-I:** A guided Day Closure ceremony and detailed sleep tracking (latency, efficiency, awakenings).
- **🛡️ Exposure & Response Prevention (ERP):** Manage fear hierarchies and execute exposure exercises directly in the app.
- **🎯 SMART Goals:** Track long-term objectives with measurable sub-milestones.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
